# Security Policy

## Reporting a vulnerability

If you believe you’ve found a security vulnerability, **please do not open a public GitHub issue**.

Preferred: report privately via **GitHub Security Advisories**:
- https://github.com/pri17m/detection-as-code/security/advisories/new

If you cannot use GitHub Security Advisories, contact the maintainer privately:
- **Email**: `SECURITY_CONTACT_TBD` (replace with a real address)

Please include:
- A description of the issue and potential impact
- Steps to reproduce (or a proof-of-concept)
- Any relevant logs or screenshots (redact sensitive data)
